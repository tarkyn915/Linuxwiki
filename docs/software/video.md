# 视频播放器

## Tsukimi

https://github.com/tsukinaha/tsukimi

GTK4 写的第三方 Jellyfin / Emby 客户端，用 MPV 播放视频、GStreamer 播放音乐

AUR安装

```
yay -S tsukimi-bin
```

## VLC

https://www.videolan.org/vlc/

官方仓库直接安装

```
sudo pacman -S vlc
```

## MPV

https://github.com/mpv-player/mpv

命令行播放器，很多播放器（如 Tsukimi）都拿它当内核

官方仓库直接安装

```
sudo pacman -S mpv
```

## Celluloid

https://github.com/celluloid-player/celluloid

MPV 的 GTK 图形前端，有完整的播放控制界面

```
sudo pacman -S celluloid
```
