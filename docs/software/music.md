# 音乐播放器

## Feishin

https://github.com/jeffvli/feishin

自托管音乐服务（Jellyfin / Navidrome / Subsonic）的桌面客户端

AUR安装

```
yay -S feishin-bin
```

## Tsukimi

https://github.com/tsukinaha/tsukimi

GTK4 写的第三方 Jellyfin / Emby 客户端，用 MPV 播放视频、GStreamer 播放音乐

AUR安装

```
yay -S tsukimi-bin
```

## Spotify

https://open.spotify.com/

AUR安装

```
yay -S spotify
```

## 网易云音乐

https://github.com/gmg137/netease-cloud-music-gtk

网易云音乐的第三方 GTK 客户端

AUR安装

```
yay -S netease-cloud-music-gtk
```

## YesPlayMusic

https://github.com/qier222/YesPlayMusic

网易云音乐的第三方 Electron 客户端，界面更现代

AUR安装

```
yay -S yesplaymusic-bin
```

# 视频播放器

## VLC

https://www.videolan.org/vlc/

官方仓库直接安装

```
sudo pacman -S vlc
```

## MPV

https://github.com/mpv-player/mpv

命令行播放器，很多播放器（如 Tsukimi）都拿它当内核

官方仓库直接安装

```
sudo pacman -S mpv
```
