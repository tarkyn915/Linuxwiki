# 代理工具

## Clash Verge Rev

https://github.com/clash-verge-rev/clash-verge-rev

基于 Tauri 的 Clash Meta（mihomo）图形客户端，体积小、内存占用低

AUR安装

```
yay -S clash-verge-rev-bin
```

## mihomo

https://github.com/MetaCubeX/mihomo

Clash Meta 的内核本体，只当命令行内核用、不需要图形界面时装这个

AUR安装

```
yay -S mihomo-bin
```

## v2rayA

https://github.com/v2rayA/v2rayA

网页界面管理的代理客户端，支持 VMess / VLESS / Shadowsocks / Trojan 等协议

AUR安装

```
yay -S v2raya-bin
```
