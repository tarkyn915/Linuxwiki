# DeepSeek Harness

https://www.deepseek.com/en/harness/

## 插件市场

dsh-market 是 DSH 可视化插件市场，在设置里浏览、搜索并一键安装插件和主题

- GitHub：https://github.com/dsh-market/dsh-market

```bash
dsh plugin --profile web add dshmarket
```

重启 dsh web，打开 **设置 → 插件市场**

## 小鲸鱼挂件

DSH 网页界面右下角的常驻小鲸鱼，显示 DeepSeek API 余额、今日已用和每轮对话消耗，气泡内容可以自定义

- GitHub：https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget

```bash
dsh plugin --profile web add dsh-whale-widget
```

刷新 DSH 网页，右下角出现小鲸鱼，右键鲸鱼打开菜单
